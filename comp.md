## Week 1 - History
- One writing system can be used by many languages
- Cuneiform looks weird
- The Epic of Gilgamesh was epic
## Week 2 - Representing Text and Numbers in Computers
- Computer stores data in bits and bytes
- Volatile memory like RAM loses contents on power loss
- ASCII table maps numbers to characters, such as code 65
## Week 3 - Structure of Text
- Markdown provides a lightweight formatting syntax
- Special characters require escaping to prevent them from being interpreted as formatting instructions
- UTF-8 is the internet dominant encoding type, matching ASCII for basic characters
## Week 4 - Manipulating Text & Text Editors
- Touch typing and keyboard mastery reduce fatigue
- Vim operates entirely within the terminal
- Regular expressions unlock advanced pattern matching
## Week 5 - Command Line Interfaces
- Commands are historically very short because the CLI originated from physical paper temrinal
- The command line uses minimal system resources while enabling fast task automation through scripts
- SSH establishes remote connection allowing control of external systems from terminal
## Week 6 - Git, GitHub, Diff, and Versioning
- Linus Torvalds created Git in 2005 as an open-source tool to manage version control locally.
- Branching enables isolated parallel development, ensuring new work does not destabilize the main branch.
- Commit messages should explain why a change was made, since the diff already shows what changed.
